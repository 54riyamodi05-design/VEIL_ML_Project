VEIL – Explainable Machine Learning for Multi-Source Phishing Detection

1. Project Description
VEIL is a machine learning project designed to detect phishing threats using URL and Email/SMS data. It also explores explainable machine learning techniques to understand model predictions.

2. Project Objectives
- Detect phishing URLs.
- Identify suspicious emails and SMS messages.
- Compare machine learning algorithms.
- Evaluate model performance.
- Explore explainability and patterns in phishing data.

3. Datasets
The project uses two datasets:

1. URL Phishing Dataset
2. Combined Email and SMS Dataset

4. Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

5. Project Files
- `URL_Phishing_Detection.ipynb` – URL detection analysis and model.
- `Email_SMS_Phishing_Detection.ipynb` – Email and SMS analysis and model.
- `data/` – Project datasets.
- `Screenshots/` – Project output screenshots.
- `Report/` – Project documentation.

6. Installation
Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn openpyxl
```

7. How to Run the Project

1. Download or extract the project folder.
2. Open Jupyter Notebook.
3. Open the `Code` folder.
4. Open the URL detection notebook or Email/SMS detection notebook.
5. Run the notebook cells in order.

8. Expected Outputs

- Data visualizations.
